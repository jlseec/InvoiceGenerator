This application generates invoices using predefined templates and runs locally using Streamlit. Follow the steps below to set up and use the application.

############Step 1 — Install Python
Ensure that Python is installed on your system. You can download the latest version from the official Python website.

############Step 2 — Install Streamlit
Open your command prompt (CMD) or terminal and install Streamlit using pip:

pip install streamlit
############Step 3 — Run the Application
Navigate to the project directory in your terminal and run:
streamlit run app.py
The application will start and open in your browser on your local host.

############Step 4 — Customize Invoice Templates (Optional)
The text content in the following files can be edited if customization is required:
Invoice_template_ABC
Invoice_template_DEF

Please note:
Only edit the text content.
Cell formatting should not be modified, as it is required for the application to function properly.

############Step 5 — Replace Logos (Optional)
You may replace the logo images used in the application.

Requirements:
Files must remain named logo1.jpg and logo2.jpg
Image format must be .jpg
Square images are recommended for best display
As long as the filenames and format remain unchanged, the images can be replaced.
